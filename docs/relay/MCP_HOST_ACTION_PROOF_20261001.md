The comparison keeps static markup and separate shell/script/host/data/dimensions/action milestones. Its literal browser program survives Worker bundling. It records at most40 bounded events: generated request IDs, method, matched response kind/error code, elapsed time, timeout, late response, unmatched-response ID type, and action-result notification without correlated reply. It never logs arbitrary payloads, arguments, credentials or raw error messages. Only the parent frame's JSON-RPC messages are accepted.

The10-second request timeout matches the control; timed-out IDs are retained in an eight-entry bounded map to detect a later reply. Late replies are recorded without changing the timed-out result. A notification is not treated as a correlated response. Cancellation is terminal and teardown clears timers/listeners. Advertised `serverTools` gates the button; advertising a capability alone is not proof that it works. A sent height is not proof the host used it.
