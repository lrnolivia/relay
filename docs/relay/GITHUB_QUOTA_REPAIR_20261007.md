## Official guidance

GitHub documents installation quota scaling and the shared allowance for tokens of one installation in [REST rate limits](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api). The configured limit for this installation remains unverified. [REST best practices](https://docs.github.com/en/rest/using-the-rest-api/best-practices-for-using-the-rest-api) explains authenticated conditional304 requests, quota deadlines and avoiding duplicate polling. [Troubleshooting](https://docs.github.com/en/rest/using-the-rest-api/troubleshooting-the-rest-api) distinguishes provider permission denials from quota403s. Increasing an eligible installation's allowance is legitimate; duplicated reads should be fixed first.
